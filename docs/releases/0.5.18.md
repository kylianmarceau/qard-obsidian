Qard 0.5.18 refreshes settings and fixes controls jumping back to the top of the page.

- **Clear sections:** compact, theme-aware groups for study preferences, review and memory, study experience, AI connections and roles, practice tests, files, import/export and backups. Quick links at the top take you to Study, AI, Tests or Files & data.
- **Stay where you are:** Advanced AI settings expand in place. Changing an AI provider updates only that role's controls; switching the review scheduler updates the retention field directly. Clearing a custom API key and editing a command-line connection no longer rebuild the page. Bulk connection updates preserve scroll position and restore the focused setting.
- **Easier AI setup:** Connect local model is the first AI connection option, with manual server details under Advanced. Existing preferences and connections carry over automatically.
- **Accessible controls:** section navigation works with keyboard focus, Advanced reports its expanded state, and connection and model fields have distinct accessible labels. The layout adapts to narrow windows and the current Obsidian theme.

All 613 automated tests, formatting, type checking, source and stylesheet lint, build and release checks pass locally. The new interaction tests cover Advanced visibility on both supported rendering paths, scroll and focus preservation, provider changes, retention availability and section navigation.

To install manually, download `main.js`, `manifest.json` and `styles.css` from this release and replace those three files in your vault's `.obsidian/plugins/qard/` folder. Reload Qard to apply the update. Keep `data.json`, the `study-backups` folder and your vault notes to preserve settings and study progress.
