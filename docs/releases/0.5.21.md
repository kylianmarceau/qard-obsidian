Qard 0.5.21 restores the home page from 0.5.19. The home-page redesign included in 0.5.20 has been removed.

- **Original home page restored:** the previous deck list, review sidebar, study controls, spacing and responsive layout are back.
- **Settings improvements retained:** consistent field alignment, compact numeric controls, simpler help text and narrow-panel layout remain, along with the custom AI Clear key fix.

All 615 automated tests, formatting, type checking, source and stylesheet lint, build and release checks pass locally. The home-page component and all styling outside settings match 0.5.19 exactly.

To install manually, download `main.js`, `manifest.json` and `styles.css` from this release and replace those three files in your vault's `.obsidian/plugins/qard/` folder. Reload Qard to apply the update. Keep `data.json`, the `study-backups` folder and your vault notes to preserve settings and study progress.
