Qard 0.5.14 refines study setup with the Study desk design and adds custom AI connections for local or hosted models.

- **Study desk:** choose decks, topics or individual cards in a compact list with course colours and clearer selection counts. Session controls sit alongside the list, with a direct choice between Normal and Cram, card filters and ordering. Daily study pacing and saved sessions keep their existing behaviour; paused cards remain excluded. The layout adapts to narrow panes and light or dark themes.
- **Custom AI connections:** connect an OpenAI-compatible chat server such as Ollama or LM Studio in Settings → Qard → AI. Configure a server address and default model, refresh available models and test the connection. Tutor, Writer, Marker and Illustrator can use the connection with optional model overrides. API keys, when required, use Obsidian's secret storage. Models must support the output formats and note tools needed by the chosen role.

All 593 automated tests, formatting, type checking, source and stylesheet lint, build and release checks pass locally.

To install manually, download `main.js`, `manifest.json` and `styles.css` from this release and replace those three files in your vault's `.obsidian/plugins/qard/` folder. Reload Qard to apply the update. Keep `data.json`, the `study-backups` folder and your vault notes to preserve settings and study progress.
