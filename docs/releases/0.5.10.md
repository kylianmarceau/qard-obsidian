Qard 0.5.10 makes FSRS rating buttons the same size as the Simple Scheduler buttons.

- **Compact rating buttons:** Again, Hard, Good and Easy share the same button dimensions and layout in both schedulers, on desktop and narrow screens.
- **Visible intervals:** FSRS interval previews appear inside each button beside the keyboard shortcut without making it taller. Each interval remains associated with its rating button for screen readers.

To install manually, download `main.js`, `manifest.json` and `styles.css` from this release and replace those three files in your vault’s `.obsidian/plugins/qard/` folder. Reload Qard to apply the update.
