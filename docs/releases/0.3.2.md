Qard 0.3.2 lets you attach a whole course folder when creating a practice test.

- **+ Folder:** search for a vault folder and attach all of its Markdown notes with one selection, including notes in subfolders.
- **Clear scope:** folder chips and the picker show note counts. Remove a folder in one click. Overlapping folders, individual notes and flashcard sources are deduplicated.
- **Works with or without a plan:** the AI receives the selected course notes for planning or direct generation. You can start from an attached folder without typing a prompt.
- **Current material:** Qard refreshes folder contents when you press Start, includes newly added notes and skips deleted notes. The chosen source snapshot is saved with the test request.

The picker attaches notes already in your Obsidian vault; it does not upload files or import PDFs. Generated practice-test folders and hidden folders are excluded.

Requires Obsidian 1.7.2 or newer. To update manually, download `main.js`, `manifest.json` and `styles.css` and replace those three files in your vault's `.obsidian/plugins/qard/` folder. Keep `data.json`, then reload Qard after running AI jobs finish.
