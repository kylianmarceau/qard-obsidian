Qard 0.6.1 lets AI features use PDFs in your vault as sources, the same way they use notes.

- **PDFs as sources:** put a PDF in your vault and choose it like a note. It works with **+ Note** and **+ Folder** when generating flashcards or a practice test, course folders in **Learn**, **Link a source note** on a card, and **Qard: Teach me this note** on an open PDF. In the note search, PDFs show their `.pdf` extension so slides and the notes beside them are easy to tell apart.
- **Read on your device:** Qard extracts a PDF's text with the PDF reader built into Obsidian, page by page, and gives the AI that text with a `[Page N]` line before each page. The PDF file is never changed. Claude Code opens PDFs with its own reader, which also sees figures; Codex receives the text of the PDFs a request names; API connections find PDFs by file name and read long ones a few pages at a time.
- **Source tracking:** cards generated from a PDF are tracked like cards from a note. Replacing the PDF with a new version shows the changed lines in **Review source updates**.
- **Smaller drafts:** a flashcard draft now saves each source's text once instead of once per card, which keeps drafts from long notes and PDFs small. Earlier drafts still load.

A PDF needs selectable text. Scans without recognised text (OCR), password-protected PDFs, files over 100 MB and PDFs with more than about 1,000,000 characters of text are explained instead of being sent empty or cut short. Lessons only suggest paragraphs for Markdown notes, never for a PDF. Text extraction was checked against PDF.js 3.11 to 5.7; PDF sources have not yet been validated on mobile.

All 682 automated tests, formatting, type checking, source and stylesheet lint, build and release checks pass locally.

To install manually, download `main.js`, `manifest.json` and `styles.css` from this release and replace those three files in your vault's `.obsidian/plugins/qard/` folder. Reload Qard to apply the update. Keep `data.json`, the `study-backups` folder and your vault notes to preserve settings and study progress.
