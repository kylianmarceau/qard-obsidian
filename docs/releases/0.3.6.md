Qard 0.3.6 fixes AI-generated flashcards being collapsed into one topic per batch. A single deck can now contain separate topics for the individual notes used to generate cards.

- **Separate AI topics:** generated cards carry their own topic. By default, the AI uses one topic per source note; describe another grouping in your request if needed.
- **One topic per note:** use this option on the review screen to assign topics from source-note names, including for unsaved drafts created by older versions. Cards without a source keep their existing topic.
- **Review and edit topics:** see and edit each card’s topic before adding it. Enter a shared name in Topic for all cards to combine the batch under one topic.
- **Reliable saving:** separate topics survive draft recovery and saving. Retrying after a save or indexing failure preserves card IDs and avoids duplicates. Deck and topic assignments are fixed once saving begins.

Already saved cards are not reorganized automatically. This update preserves existing cards, settings and study history.

Requires Obsidian 1.7.2 or newer. Update under Settings → Community plugins → Check for updates, then reload Qard after any running AI jobs finish. For a manual update, replace main.js, manifest.json and styles.css in your vault’s .obsidian/plugins/qard/ folder, keeping data.json.
