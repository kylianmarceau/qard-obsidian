Qard 0.5.2 improves the display of running agents and background tasks.

- **Running tasks:** a clearer popover with separate task names, course or test details, agent labels, elapsed time, and Cancel controls. Long names and model labels wrap without being cut off.
- **Waiting screens:** consistent panels for course mapping, test creation, marking, and lesson preparation. Status, timing, and controls stay aligned on narrow screens; the tutor hint stays inside the lesson waiting panel.
- **Navigation:** dismiss the running-task list with Escape or a click outside it. Escape returns keyboard focus to the running indicator.

Your notes, settings, review history, saved sessions, and exam plans are preserved. No data migration is required. All 341 automated tests and the source, stylesheet, build, and release checks pass.
