Qard 0.5.20 tidies settings and the deck library so study controls are easier to find and use.

- **Consistent settings:** aligned fields, compact number inputs, shorter help text and a simpler heading. AI connection and model controls follow the same layout. Settings stack cleanly when the panel is narrow.
- **Clear key fix:** clearing the custom AI API key also clears any unsaved text in its field, preventing that draft from being saved again by a later change event.
- **Simpler deck library:** today's review appears above the deck list, with a clear caught-up state when nothing is due. New card stays beside the heading, and Study and Practice test sit below the library. Card counts use readable number formatting and correct singular labels.

All 615 automated tests, formatting, type checking, source and stylesheet lint, build and release checks pass locally. Settings were also checked in Obsidian 1.14.4 at wide and narrow window sizes.

To install manually, download `main.js`, `manifest.json` and `styles.css` from this release and replace those three files in your vault's `.obsidian/plugins/qard/` folder. Reload Qard to apply the update. Keep `data.json`, the `study-backups` folder and your vault notes to preserve settings and study progress.
