Qard 0.5.9 corrects same-session flashcard repeats: only **Again** brings a card back in the current study session.

- **Again repeats:** the missed card stays unfinished and returns at its scheduled FSRS learning or relearning time. Pressing Again on the returning card schedules another repeat.
- **Hard, Good and Easy finish the card:** these ratings count the card as completed for the current session, including after an Again repeat. Their FSRS due dates and memory updates are preserved for later study sessions.
- **Existing saved sessions:** Hard/Good repeats created by earlier versions are removed when loading or resuming, while Again repeats, unvisited cards, review history and schedules are preserved. Undo restores the prior rating, progress and repeat queue.

To install manually, download `main.js`, `manifest.json` and `styles.css` from this release and replace those three files in your vault’s `.obsidian/plugins/qard/` folder. Reload Qard to apply the update.
