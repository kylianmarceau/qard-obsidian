Qard 0.5.16 makes connecting local AI models easier.

- **Connect local model:** Qard automatically finds running Ollama and LM Studio servers on their standard local ports. Choose a server and model from dropdowns, then select **Test and connect**. No server address is needed.
- **Check before saving:** Qard checks JSON replies and note tools using synthetic text, without sending vault notes. Failed checks leave your connection unchanged. You can cancel the check, and it stops waiting after one minute.
- **Choose how to use the model:** use it for all AI roles, or keep your existing role selections. Manual server addresses, model names, optional API keys and connection tests remain available under **Advanced AI settings**.
- **Clear setup guidance:** stopped servers, empty model lists and servers requiring an API key have their own instructions. **Try again** checks for servers after you start them. On mobile, use Advanced settings to connect to your computer's network address.

Start your local server and download a chat model before connecting. Qard does not install models or start servers.

All 607 automated tests, formatting, type checking, source and stylesheet lint, build and release checks pass locally.

To install manually, download `main.js`, `manifest.json` and `styles.css` from this release and replace those three files in your vault's `.obsidian/plugins/qard/` folder. Reload Qard to apply the update. Keep `data.json`, the `study-backups` folder and your vault notes to preserve settings and study progress.
