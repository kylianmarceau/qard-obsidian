Qard 0.5.19 adds automatic setup for local models served by oMLX on Mac.

- **Find oMLX automatically:** Connect local model now checks oMLX at `http://localhost:8000/v1` alongside Ollama and LM Studio. Choose a model and select Test and connect to check JSON replies and note tools before saving.
- **Authenticated servers:** if oMLX requires an API key or uses another port, use Advanced settings to enter the address and key, refresh models and test the connection. Select Custom AI under AI roles to use it. Qard connects directly to the same oMLX server you can use with Claude Code and OpenCode.
- **Updated setup guidance:** settings, local-server instructions and the guide now include oMLX.

All 615 automated tests, formatting, type checking, source and stylesheet lint, build and release checks pass locally. Live checks with oMLX 0.7.1.dev1 and `Qwen3.5-4B-MLX-4bit` passed JSON output and the synthetic note-tool round trip without sending vault notes. Other models and full study tasks were not exercised.

To install manually, download `main.js`, `manifest.json` and `styles.css` from this release and replace those three files in your vault's `.obsidian/plugins/qard/` folder. Reload Qard to apply the update. Keep `data.json`, the `study-backups` folder and your vault notes to preserve settings and study progress.
