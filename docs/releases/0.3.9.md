Qard 0.3.9 removes automatic clipboard access, fixes the community review’s CSS warnings, and narrows note discovery. It also corrects the dependency lock file so the release builds from a clean installation.

- **No clipboard access:** Select answer reveals and selects the answer’s Markdown. Copy it with your device’s usual Copy action or Ctrl+C / Cmd+C; Qard never reads or writes the system clipboard.
- **Narrower discovery:** card indexing, import discovery, course source expansion, source pickers and API note tools skip hidden Markdown files. The course picker derives folders from Markdown notes instead of listing every loaded file, including attachments. API tools also exclude the configured tests folder.
- **CSS fixes:** review annotations use compatible borders, feedback markers use CSS variables instead of !important, and map panels and rating buttons use explicit state classes instead of :has().
- **Release checks:** the official Obsidian CSS rules run with zero warnings against the review’s Electron 30 baseline on every release. Builds are also checked for clipboard API references.

Vault enumeration remains necessary to discover flashcards and choose notes across the vault. It is a disclosed capability recommendation, not a failing lint check. See [review notes](https://github.com/kylianmarceau/qard-obsidian/blob/main/docs/REVIEW_NOTES.md) for details.

Requires Obsidian 1.7.2 or newer. Update under Settings → Community plugins → Check for updates, then reload Qard after any running AI jobs finish. To update manually, replace main.js, manifest.json and styles.css in your vault’s .obsidian/plugins/qard/ folder. Keep data.json to preserve settings and review history.
