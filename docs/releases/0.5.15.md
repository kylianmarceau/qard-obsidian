Qard 0.5.15 fixes the Obsidian community review warning in Anki import.

- Anki conversion now uses Obsidian's DOM helpers for media, math and table markers. Created nodes are adopted into the detached import document, preserving conversion without inserting imported content into the visible vault interface.
- Source lint now enforces the DOM helper rule for every source file, including the Anki importer.

All 593 automated tests, formatting, type checking, source and stylesheet lint, build and release checks pass locally.

To install manually, download `main.js`, `manifest.json` and `styles.css` from this release and replace those three files in your vault's `.obsidian/plugins/qard/` folder. Reload Qard to apply the update. Keep `data.json`, the `study-backups` folder and your vault notes to preserve settings and study progress.
