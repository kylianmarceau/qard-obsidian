Qard 0.5.6 introduces a new flashcard logo and a clearer Statistics page.

- **New Flip logo:** a turning flashcard replaces the layered-stack mark in the Obsidian toolbar, workspace tab and Qard page header. It follows the current theme and stays consistent across these locations.
- **Redesigned Statistics:** review performance, study activity, ratings, upcoming reviews and deck progress are easier to scan. FSRS memory estimates and details about the data are available in expandable sections.

To install manually, download `main.js`, `manifest.json` and `styles.css` from this release and replace those three files in your vault’s `.obsidian/plugins/qard/` folder. Reload Qard to apply the update.
