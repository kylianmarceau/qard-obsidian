Qard 0.6.0 adds Anki export, personal FSRS parameters and nested decks with their own options, and redesigns how a card's source notes are linked.

- **Export to Anki:** in **Settings → Qard → Import and export → Export**, choose **Anki package (.apkg)**. Basic cards, reverse pairs and cloze cards become Anki notes with their decks, tags, formatting, math, and linked images and audio. Topics become subdecks. **Include review progress** adds due dates, intervals, FSRS memory, paused cards and your rating history; turn it off to share a deck. Exporting the same cards again updates them in Anki instead of duplicating them. Image-occlusion cards are not exported and are counted in the result.
- **Personalise FSRS:** in **Settings → Qard → Review and memory**, fit the scheduler's parameters to your own ratings. It runs on your device, needs 400 ratings (50 of them a day or more after the previous one), and compares your parameters with the defaults before you apply them. Applying updates each card's memory estimate without moving due dates already set; **Reset to defaults** undoes it.
- **Nested decks:** a deck named `Biology::Cells` appears under **Biology** in the library. Expand or collapse a parent, and choose **Study all** to study it with every deck beneath it. Nested Anki decks now arrive grouped the same way.
- **Deck names from folders:** optionally name notes without `qard-deck` after their folder, so `Courses/Networks/tcp.md` joins the deck `Courses::Networks`. This is off by default; turning it on regroups those cards while their review history stays with each card.
- **Deck options:** set a target retention and a daily new-card limit for a deck from the options button beside **Study**. Both apply to the decks nested under it. A nested deck's own target replaces its parent's; new-card limits stack with parent limits and your overall allowance.
- **Linking source notes:** the Source notes section of a card has a clearer layout. **Link a source note** opens a search that lists recently edited notes and filters as you type; choosing a note links it.

The Anki package was verified by reading it back with Qard's own importer; it has not yet been validated by importing into Anki itself. The parameter comparison is measured on the same reviews used for fitting, so it shows fit and not a guarantee about future reviews. Deck new-card limits count cards introduced after this version is installed, and deck options are stored by deck name, so a renamed deck needs its options set again. Install this version on every device before using personal parameters or deck options with sync; an older version does not keep them when it saves settings. These features were checked with automated tests and have not yet been validated on mobile.

All 670 automated tests, formatting, type checking, source and stylesheet lint, build and release checks pass locally.

To install manually, download `main.js`, `manifest.json` and `styles.css` from this release and replace those three files in your vault's `.obsidian/plugins/qard/` folder. Reload Qard to apply the update. Keep `data.json`, the `study-backups` folder and your vault notes to preserve settings and study progress.
