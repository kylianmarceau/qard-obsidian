Qard 0.5.22 fixes alignment on AI waiting screens and adds a more active loading animation.

- **Aligned waiting screens:** course mapping and practice-test creation keep the loading icon beside the task title. The Writer pill aligns with the description and review-card content, and the mapping delete action sits at the right edge.
- **Animated study cards:** loading indicators now show cards lifting, flipping and shuffling on a faster cycle. Reduced-motion settings keep the cards still.

The existing page layout and study workflows are preserved. Waiting screens were checked with long course and model names, narrow panes and no cards due.

All 615 automated tests, formatting, type checking, source and stylesheet lint, build and release checks pass locally.

To install manually, download `main.js`, `manifest.json` and `styles.css` from this release and replace those three files in your vault's `.obsidian/plugins/qard/` folder. Reload Qard to apply the update. Keep `data.json`, the `study-backups` folder and your vault notes to preserve settings and study progress.
