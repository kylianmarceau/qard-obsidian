# Welcome to the Qard test vault

This vault contains only example notes for development. Open **Qard** from the left ribbon or run **Qard: Open Qard**.

Try:

1. Open Computer Networks: both networking files appear as one deck.
2. Expand Transport Layer: compact questions appear, not expanded answers.
3. Build a study session with Computer Networks and Algorithms. Choose **All cards**.
4. Press Space, then 1 / 2 / 3 / 4. Press F for focus and Escape to leave it.
5. Preview the network diagram and the math examples.
6. Select some text here and run **Qard: Create card from selection**.
7. Edit a card in Qard and then open its source note.
8. Disable and enable the plugin to confirm review history persists.

A useful answer to select: **Active recall** means retrieving an idea from memory before looking at the answer.
