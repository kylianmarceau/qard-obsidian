# Complexity

> [!qard]- What is the time complexity of binary search?
> $O(\log n)$ on a sorted random-access sequence.

# Data structures

<!-- qard-id: example-stack -->
> [!qard]- How does a stack remove items?

<!-- qard-id: example-code -->
> [!qard]- What does this function return?
>
> ```python
> def double(x):
>     return x * 2
> ```
> <!-- qard-answer -->
> Twice the value of `x`. For example, `double(4)` returns `8`.
