# Application Layer

<!-- qard-id: example-dns -->
> [!qard]- What does DNS do?
> DNS maps domain names to IP addresses.
>
> A lookup can use caching and several name servers.

<!-- qard-id: example-http -->
> [!qard]- What is an HTTP request?
> A message from a client to a server, such as:
>
> ```http
> GET /index.html HTTP/1.1
> Host: example.test
> ```
